# Technobabble v1.13.1

This maintenance release includes the full FIGlet distribution copyright, conditions, and disclaimer alongside the Standard font in the Windows ZIP, Linux binaries, and Linux source archive. The project continues to use Apache 2.0 for its application source. [Release downloads](https://github.com/lordtempis/technobabble/releases/tag/v1.13.1)

| Download | Install or run |
| --- | --- |
| [Debian or Ubuntu (64-bit)](https://github.com/lordtempis/technobabble/releases/download/v1.13.1/technobabble_1.13.1-2_amd64.deb) | In the download folder, run `sudo apt install ./technobabble_1.13.1-2_amd64.deb`. Launch with `technobabble`. |
| [Windows ZIP](https://github.com/lordtempis/technobabble/releases/download/v1.13.1/Technobabble-1.13.1.zip) | Extract the ZIP. Open `Technobabble.exe` for the desktop app, or run `.\Technobabble-Terminal.exe` from the extracted folder in PowerShell. |
| [Portable Linux binary (x86-64)](https://github.com/lordtempis/technobabble/releases/download/v1.13.1/technobabble-1.13.1-linux-x64.tar.gz) | Extract the archive on glibc-based Linux. Run `./technobabble` from the extracted folder. |
| [Linux source](https://github.com/lordtempis/technobabble/releases/download/v1.13.1/Technobabble-Linux-1.13.1-source.tar.gz) | Extract and build with the .NET 10 SDK. |

If you already use the signed Technobabble repository, run `sudo apt update` followed by `sudo apt install --only-upgrade technobabble`. The package version is `1.13.1-2`. [Optional repository setup](../../README.md#debian-and-ubuntu-apt)

To verify your downloads on Linux, place them beside the [SHA-256 manifest](https://github.com/lordtempis/technobabble/releases/download/v1.13.1/v1.13.1-SHA256SUMS) and run `sha256sum --ignore-missing -c v1.13.1-SHA256SUMS`.
