# Technobabble v1.13.2

Classic Mode's `pv` pane now uses the same simulated file transfers as Studio. Each pane cycles through 12 shuffled filenames with distinct sizes, including logs, packet captures and backups. Each transfer reaches 100% before the next starts. No network access is needed for the simulation.

| Download | Install or run |
| --- | --- |
| [Debian or Ubuntu (64-bit)](https://github.com/lordtempis/technobabble/releases/download/v1.13.2/technobabble_1.13.2-2_amd64.deb) | In the download folder, run `sudo apt install ./technobabble_1.13.2-2_amd64.deb`. |
| [Windows ZIP](https://github.com/lordtempis/technobabble/releases/download/v1.13.2/Technobabble-1.13.2.zip) | Extract the ZIP. Open `Technobabble.exe` or run `.\Technobabble-Terminal.exe` in PowerShell. |
| [Portable Linux (x86-64)](https://github.com/lordtempis/technobabble/releases/download/v1.13.2/technobabble-1.13.2-linux-x64.tar.gz) | Extract on glibc-based Linux and run `./technobabble` in the extracted folder. |
| [Linux source](https://github.com/lordtempis/technobabble/releases/download/v1.13.2/Technobabble-Linux-1.13.2-source.tar.gz) | Extract and build with the .NET 10 SDK. |

Existing APT users can run `sudo apt update` and `sudo apt install --only-upgrade technobabble`. The package version is `1.13.2-2`. [Optional repository setup](../../README.md#debian-and-ubuntu-apt)

Each download has a SHA-256 checksum. To verify downloads on Linux, place them alongside the [checksum manifest](https://github.com/lordtempis/technobabble/releases/download/v1.13.2/v1.13.2-SHA256SUMS) and run `sha256sum --ignore-missing -c v1.13.2-SHA256SUMS`.
