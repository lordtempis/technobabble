# Technobabble v1.13

This tag brings together the Windows and Linux v1.13 source trees. It includes Classic, Studio's pane editor and named layouts, character-by-character code typing, and Relay Watch's twelve shuffled incidents.

| Artifact | Use |
| --- | --- |
| `Technobabble-1.13.zip` | Windows desktop and terminal executables, complete Windows source, tests, and notices. |
| `technobabble_1.13.0-1_amd64.deb` | Native Linux terminal application for x86-64 Ubuntu. Depends on the Linux .NET 10 runtime. |
| `technobabble-1.13.0-linux-x64.tar.gz` | Portable x86-64 Linux terminal binary with its .NET runtime. Extract and run on glibc-based Linux. |
| `Technobabble-Linux-1.13.0-source.tar.gz` | Standalone Linux source distribution, build instructions, tests, and packaging script. |

The [SHA-256 manifest](v1.13-SHA256SUMS) identifies the original three artifacts. To verify downloaded files on Linux, put the artifacts and the manifest in one directory and run:

```sh
sha256sum -c v1.13-SHA256SUMS
```

In PowerShell, use `Get-FileHash -Algorithm SHA256 <filename>` for each file and compare the result with the manifest. A new build can have a different binary checksum. The manifest describes the distributed v1.13 files.

The portable binary was added after the original release and has a [separate checksum](technobabble-1.13.0-linux-x64.tar.gz.sha256). Download it beside the archive and run `sha256sum -c technobabble-1.13.0-linux-x64.tar.gz.sha256`.

Get the packages from the [v1.13 release](https://github.com/lordtempis/technobabble/releases/tag/v1.13). Packaging instructions are in the [contributor guide](../../CONTRIBUTING.md).
